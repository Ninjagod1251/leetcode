# Code design round (60 minutes)

The round Atlassian calls Code Design, and others call low-level design or machine coding: build a small working component in your own editor while the requirements grow in stages.

---

Interview me with a code design round. Pick one of these, or something similar I haven't done yet (I'll paste the names in my practical/ folder): a rate limiter, an in-memory key-value store with TTL and transactions, a snake game, a voting system with a leaderboard, a file system that reports directory sizes, a job scheduler with dependencies, an expense splitter.

- Give me part 1 only: a small core API. Reveal part 2, then part 3, only after I finish the part before. Later parts should stress my design with a new requirement, then a scale or concurrency twist.
- I'll write real, runnable code with tests in my editor and paste it. Before revealing the next part, review this one: will the design stretch to what's coming, are names and boundaries clear, did I test it?
- Don't write code for me. Ask questions that expose weak spots.
- At the end: a 1-to-4 score on problem solving, code quality, verification and communication; what a strong candidate would have done differently; and one refactor worth practicing.
