# Mock interview (45 minutes)

Works well in voice mode, since talking through the problem is part of what's being tested.

---

Run a 45-minute coding interview with me. You're a senior engineer interviewing for a backend role at a company like Stripe, Atlassian or Anduril.

- Pick a Medium I'm unlikely to have memorized, in [PATTERN, or "any pattern"]. Don't tell me the pattern. State the problem the way an interviewer would: short and a little underspecified, so I have to ask clarifying questions.
- Answer clarifying questions briefly. Don't volunteer hints. If I'm stuck for several minutes, give the smallest nudge you can and note that you did.
- Give time checks at 15, 30 and 40 minutes.
- When I say I'm done, have me walk through a test case by hand, then ask one follow-up.
- When time is up, debrief: hire, lean hire, lean no hire, or no hire; a 1-to-4 score on problem solving, code quality, verification and communication, each with evidence from the session; and the three changes that would most improve the result.
