# Solutions

[LeetSync](https://github.com/3ba2ii/LeetSync) writes here from accepted LeetCode submissions (its subdirectory setting is `solutions`). Each problem folder holds:

- `README.md`: the problem with its link and difficulty, written by LeetSync
- `<slug>.<ext>`: the accepted code, written by LeetSync
- `approach.md`: my notes and attempt history, written with `lc.py log`
